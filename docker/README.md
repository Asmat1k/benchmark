# Структура Docker-окружения

Все команды выполняются из корня репозитория. Основные точки входа остаются в `Makefile`.

| Каталог | Содержимое |
|---|---|
| `images/` | Dockerfile четырёх образов: server, browser, router, analyzer |
| `config/` | Закреплённые образы, список пакетов и профиль Chromium seccomp |
| `commands/` | Команды сборки, запуска, измерения, анализа, диагностики и очистки |
| `runtime/` | Скрипты, выполняемые внутри контейнеров: браузер, сеть, сбор ресурсов |
| `lib/` | Общие части команд: маршруты, контроллер, проверки релиза и очистка |
| `diagnostics/` | Python-инструменты калибровки и диагностики |
| `tests/` | Проверки Python-инструментов и служебных сценариев |
| `docs/` | Описание запуска калибровки |

`make build` собирает образы, `make docker-test` запускает проверки из `tests/` без измерительной сети. Остальные команды Make сохранены.

Старые пути в сохранённых результатах и исторических отчётах описывают расположение файлов на момент сбора. Эти артефакты не переписываются при реорганизации.
