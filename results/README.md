# Результаты стенда

Рабочая папка для новых измерений. Старые тестовые запуски, серии и архивы удалены перед итоговым сбором.

| Каталог | Назначение |
|---|---|
| [main/](main/) | Новые основные серии: расписание, допуск, снимки, исходные измерения и отчёты |
| [verify/](verify/) | Новые короткие проверки среды, сети и измерителя |
| [archives/](archives/) | Архивы Docker-образов и контрольные суммы, создаваемые `make archive` |

В Git сохраняется только этот README. Результаты, логи и архивы исключены правилами `.gitignore`. Инструменты создают рабочие каталоги и подпапки отдельных запусков самостоятельно. Для каждой новой серии используйте новое имя; исходные данные начатой серии не перезаписываются.

В серии встречаются `schedule.json` (назначения), `ledger.json` (учёт блоков), `admission.json` (допуск), `snapshot/` (снимок среды и исходников), `outcomes.json` (исходы), raw и частичные данные, `derived/` (производный отчёт). Конкретный набор зависит от этапа и версии стенда.

Подготовка новой серии не требует старых результатов: исторические ограничения calibration/generator failed и A/A partial берутся из [политики](../configs/policies/exploratory.json) и сохраняются в допуске. Это сведения о прежнем исследовании, а не новые проверки готовности. Старые отслеживаемые артефакты доступны в истории Git.

Порядок подготовки и запуска — [docs/run.md](../docs/run.md), трактовка результатов — [docs/analysis.md](../docs/analysis.md). Повторный анализ новой серии: `make analyze SERIES=results/main/имя-серии`.
