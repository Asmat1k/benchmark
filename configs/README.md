# Конфигурация и машинные контракты

Здесь находятся читаемые программой параметры стенда. Они связываются хешами со снимком серии: изменение конфигурации требует подготовки новой серии, а не правки сохранённых результатов.

| Файл / папка | Назначение |
|---|---|
| [plan.json](plan.json) | Размер и частота кадров, число слотов, seeds, блоки, сессии и бюджет |
| [profiles.json](profiles.json) | Четыре профиля netem: задержка и потери на направление, скорость и MTU |
| [thresholds.json](thresholds.json) | Пороги измерения, проверки и статистических решений |
| [contracts/](#contracts) | Версионированный контракт обмена и среды |
| [policies/](#policies) | Правила исследовательского сбора |
| [schemas/](#schemas) | JSON Schema для параметров, raw и служебных документов |

В `plan.json` сохранён `finite-browser-study-v1`; текущий исследовательский путь явно использует политику `exploratory-browser-study-v2`. Эти режимы нельзя считать одной и той же процедурой допуска. Описание — [эксперимент](../docs/experiments.md), формат обмена — [протокол](../docs/protocol.md).

<a id="contracts"></a>

## Контракт протокола

[protocol.json](contracts/protocol.json) закрепляет машинное описание протокола и требований стенда. Его используют проверки и снимки контекста серии; человекочитаемое описание находится в [docs/protocol.md](../docs/protocol.md).

Подпапок нет. Параметры конкретного плана и сетевых профилей лежат уровнем выше, в [configs/](README.md).

<a id="policies"></a>

## Политики исполнения

[exploratory.json](policies/exploratory.json) описывает текущий `exploratory-browser-study-v2`: 240 назначений, лимиты времени, сохранение всех исходов, отсутствие повторов и замен, обязательные проверки целостности и ограничения выводов.

Политику применяет [admission.exploratory](../src/analysis/admission/exploratory.py), серию выполняет [execution](../src/README.md#analysis-execution). Подпапок нет. Контекст — [docs/experiments.md](../docs/experiments.md).

<a id="schemas"></a>

## JSON-схемы

Схемы описывают структуру входных параметров и сохраняемых документов: plan/profiles/thresholds, слоты и события, ресурсы и серверные счётчики, manifest, ledger, проверки, collection, freeze и completion.

Сопоставление данных со схемами и дополнительные проверки выполняет [measurement/raw.py](../src/analysis/measurement/raw.py). Примеры корректных и некорректных документов находятся в [fixtures](../src/README.md#analysis-tests-fixtures). Схемы проверяют форму данных; правила идентичности, хешей и полноты дополнительно проверяются кодом. Подпапок нет.
