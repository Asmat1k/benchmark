# Документация стенда

Актуальный режим — exploratory-browser-study-v2: фиксированное расписание и сохранение всех исходов. Основной эксперимент запускает пользователь.

- [Запуск и продолжение](readiness/run-today.md).
- [Правила сбора и ограничения](readiness/exploratory-browser-study-v2.md).
- [Архитектура](architecture.mmd), [измерение](measurement.md), [метрики](metrics.md).
- [Анализ](analysis.md), [эксперименты](experiments.md), [проверки](verification.md).

`protocol.md` остаётся замороженным контрактом версии 1: его исходные байты связаны с сохранёнными измерениями. Исторические условия допуска внутри него не отменяют действующую политику exploratory-browser-study-v2. Схемы и синтетические примеры пока находятся в `schemas/` и `fixtures/` и используются программой.

Старые разборы, планы и передачи удалены из рабочей документации. Их исходные версии доступны в истории Git; результаты измерений сохранены в `results/`.
