# Документация стенда

Текущий режим — **exploratory-browser-study-v2**: последовательное сравнение WS/WT-S/WT-D на фактическом Docker-стенде с фиксированным расписанием и сохранением всех исходов. Основной эксперимент запускается пользователем отдельно.

| Документ | Содержание |
|---|---|
| [Запуск](run.md) | Требования, сборка, короткие проверки, подготовка новой серии, основной сбор, продолжение и отчёт |
| [Архитектура](architecture.mmd) | Клиент, runner, router, сервер и анализ |
| [Протокол](protocol.md) | TLS, обмен READY/ACK, бинарный кадр и сетевые профили |
| [Измерение](measurement.md) | Слоты, события, ресурсы, checkpoint и сохранение при отказе |
| [Метрики](metrics.md) | RTT, Q/S/U, дедлайн/горизонт и дополнительный разбор хвоста |
| [Анализ](analysis.md) | Все назначения, неизвестные данные, таблицы, графики и парная статистика |
| [Эксперимент](experiments.md) | План из 240 запусков, допуск, снимки, лимиты и возобновление |
| [Проверки](verification.md) | Команды и область применимости проверок |

Машинные контракты, политика и JSON-схемы находятся в [configs/](../configs/README.md), синтетические примеры — в [src/analysis/tests/fixtures/](../src/README.md#analysis-tests-fixtures). Они используются программой и не дублируются в документации. Краткий обзор проекта — в [корневом README](../README.md), устройство Docker-каталогов — в [docker/README.md](../docker/README.md).

Текущий сбор исследовательский: исторические calibration/generator failed и A/A partial остаются в results/ без изменения статусов. Полная приёмка и мощность 80% не заявляются. Старые разборы и передачи доступны в истории Git.
