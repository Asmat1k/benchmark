# Итог экспериментальной приёмки после D6

**Не готов к основной серии.** Не получены полная калибровка задержек, потерь и полосы, результаты проверки генератора, интервальные оценки A/A и влияния мониторинга. Официальный пилот и power не проводились. Для выбора окончательных параметров, выпуска freeze и независимого экспериментального воспроизведения отсутствуют обязательные входы.

По уточнению пользователя длительные проверки пропущены. Исходный план оценивал одну только последовательность A/A, monitoring и pilot минимум в 15 ч 07 мин для двух обязательных режимов, без развёртывания и повторов. Отдельный реальный UDP-сбор по исправленному плану требует около 30–35 мин. Запущенный прежде длительный синтетический тест D6 остановлен по указанию пользователя (exit 137), его частичный журнал сохранён. Экспериментальный статус этих серий остаётся not_run; предыдущие записи разработки сохранены.

Архив D6 повторно загружен, 648 контрольных сумм пакета проверены, сборка из чистой копии по locks завершилась. В реальном коротком тесте маршрута получены по три точных ответа WS, WT-S и WT-D, подтверждены отказы при недоверенном TLS. Для рабочего снимка отдельная короткая серия дала монотонные часы, минимальный положительный шаг 0,099999998 мс и p99 разностей 0 мс. Нулевой p99 означает повтор одинаковых квантованных значений. Это результат конкретного запуска на Chromium 140.0.7339.16. Оба набора raw прошли сверку SHA. Пять эталонных тестов статистики прошли. В короткой проверке пути отказы Git/контроллера воспроизведены на временных данных с подставным исполнителем.

13 ноября на локальном релизе `d1573e82d7b61d01fb9df88f52469f256031f1d3` повторён таймер. Оба manifest фиксируют этот commit и dirty=false. Запуск занял 67,38 с, шаг 0,099999994 мс, p99 0 мс. Предварительный verify принял таймер и завершился с кодом 2. В девяти остальных строках нет формальных отчётов для текущей комбинации source/ENV. В частности, отдельные проверки сборки, TLS, пути, raw и статистики описаны в матрице; их результаты не были опубликованы комплектом ранних gates этого релиза. [Отчёт таймера](../../results/verify/diagnostic/timer-timer.RKMg3sCH-report/report.json) · [Предварительный verify](../../results/verify/readiness/host/partial-verify.json).

В ветке main один новый локальный коммит исправлений поверх D6. Рабочие исходники совпадают с ним, индекс пуст. Новые документы и результаты приёмки оставлены в рабочем каталоге отдельно от кода. Сохранён исходный пользовательский .agents/plan/. Контейнеры и сети задания остановлены, lock проверен, временные ключи и копии удалены после сверки raw. Архивы D6 сохранены. Независимый рецензент пересчитал таймер и сверил 112 хешей исходников с Git и 132 хеша отчёта. [Проверка релиза](reviews/04-release.md). Точка продолжения при отдельном разрешении длительных проверок — подтвердить итоговую версию и образы на выбранной среде, принять актуальные ранние gates и провести независимую калибровку. При failed/inconclusive сохранить первичные наблюдения и причину, определить следующую диагностику до сбора. После калибровки следуют генератор, A/A, monitoring, pilot и power. Freeze и воспроизведение зависят от всех предыдущих результатов. Готовность к main и разрешение на её проведение отсутствуют.
