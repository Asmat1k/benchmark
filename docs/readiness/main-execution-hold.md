# Запрет запуска итогового прогона

15 ноября2026, последняя инструкция пользователя после браузерного generator:

> только запомни, не запускай финальный / итоговый тест!

Итоговый/main прогон не запускать. Это более позднее решение имеет приоритет над прежним сроком его старта в течение12часов. Автономная работа продолжается только на подготовительных проверках/контролях/пилоте/пакете допуска. Готовность или freeze не являются разрешением запуститьmain. finite-series-run.py явно отвергает phase=main до создания измерительного execution и до сети. Самостоятельно снимать этот запрет нельзя; нужно новое явное решение пользователя.

Уточнение пользователя: «нет, итоговый запускай, самое тестирование стенда ради которого он делается - нет». Рабочее толкование, явно сообщённое пользователю: итоговый readiness/acceptance разрешён; основной сравнительный main запрещён. Блокировка в wrapper касается только phase=main, а не проверок готовности, controls или pilot.
