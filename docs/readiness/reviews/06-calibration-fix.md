# Независимая приёмка исправления таблиц соседей

Рецензент /root/calibration_review. Model/effort унаследованы, подтверждённые значения неизвестны. Автор исправления /root/calibration_fix. Зафиксированный пакет results/verify/readiness/calibration-fix/manifest.json на базе 724d491783f7bfbc18d9ec69482b13888fff75d9. Все пять SHA256 соответствуют фактическим файлам до повторных тестов.

**Исправление принято в автономном объёме.** calibration.sh вызывает настройку после создания veth и до снимка контекста и первичного сбора. Четыре permanent neighbor entries используют фактический MAC противоположного конца собственного линка. Адреса .10 заданы на router, .2 заданы на endpoint. Временный helper получает NET_ADMIN только в собственном namespace endpoint. Изменение ограничено diagnostic calibration, рабочие browser/server не получают новых capabilities. Снимки четырёх таблиц входят в seal. Штатный cleanup удаляет соответствующие namespace вместе с контейнерами.

Независимо повторены пять тестов с подставным Docker, exit 0 за 1,504 с. Проверены четыре точные команды настройки, адреса/MAC/namespace, отсутствие NET_ADMIN в readback, остановка до второго endpoint при отказе первой установки. Три оставшихся теста защищают строгую сверку UDP ID/drops, уникальность collection и центральное окно скорости. Синтаксис обоих shell-файлов корректен. [Команды, UTC, длительность, exit и SHA](../../../results/verify/readiness/calibration-review/neighbor-tests.json).

Реальное отсутствие ARP и фактические permanent записи в Linux kernel этой проверкой не подтверждены. Такой вывод потребует нового отдельно разрешённого сбора. Исправление не устраняет опоздания отправителя и статистическую зависимость. Частота100Гц, требования к каждому слоту, единицам наблюдения, потере и полосе сохранены.
