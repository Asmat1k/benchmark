# Независимая исходная проверка

Аудитор `/root/auditor`. Запрошены унаследованные model/effort, подтверждённые значения неизвестны. Исходный релиз `aeda8e1d36bc5bc87042a6e497eefaf84213397e`, ветка main, начальное состояние `?? .agents/plan/`. Проверены входные контракты и исполнимость переходов. Работа аудитора охватывает исходную версию. Исправления принимает другой исполнитель.

Контракт волн 1–2 задаёт 10000 echo по 256 байт, 100 Гц, исходящий и обратный знаменатели потерь, отдельную saturation, критерии генератора и A/A/monitoring. Их численные требования переносятся в docs/verification.md и acceptance.py. Предусмотрены full-n sign test, Holm4, ранговые интервалы и bootstrap целыми парами. Наличие вычислений не доказывает эквивалентность, отсутствие дрейфа либо фактическую пригодность среды.

**Проверенные границы.** Хостовая `test_release_guard.py` прошла 2/2 с реальным Git и подставной сетью во временных деревьях. Варианты docs-only commit, dirty source и untracked source отказывали до сети. Контроль на совпадающем релизе достигал подставного исполнителя. Исполнение acceptance-тестов системным Python остановилось при импорте numpy; научные проверки на этом интерпретаторе не выполнялись. Сеть, основной набор данных и Docker аудитор не использовал. Тест хостового guard отдельно от полного initial main admission.

**Воспроизводимость.** Команды, UTC, длительности, config SHA, хост, интерпретатор, коды и SHA stdout/stderr находятся в `results/verify/readiness/audit/commands.json` (SHA256 c3c6ef7a068438df44e22bd239ddc45d4a6287eabf6241c22400a4a75790bcac). `results/verify/readiness/audit/source-inventory.json` (SHA256 33adf645706c51bbf13b80998fdad657af3894f4cff2446a756646ee6bba95cb) перечисляет доступность материалов и SHA256 файлов, в том числе восьми исходных diff по исполняемой части и документации D0–D6. Для tar здесь учитывался только размер. Инвентаризация устанавливает идентичность и доступность документов. Она не является проверкой результата соответствующего запуска.

Исходное заключение — **не готов**. Отсутствуют текущие принятые сборы, A/A, monitoring, официальный pilot/power, freeze и независимое экспериментальное воспроизведение. Тесты и рецензии D0–D6 относятся к разработке.
