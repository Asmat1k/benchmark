# Устранение ARP в последующих диагностических сборах

Исполнитель /root/calibration_fix, model/effort унаследованы, подтверждённые значения неизвестны. Основание — наблюдения calibration.ZQRTHB2H, r20p1-before. UDP ingress/survivors дают 102 прямых потери, netem сообщает 104 drops. 9905 доставленных кадров и 2949898 байт совпадают с 9898 UDP по 298 байт и 7 ARP по 42 байта. Полных egress ARP наблюдений нет, поэтому два drops нельзя достоверно отнести к UDP.

Перед следующими подсериями calibration.sh получает MAC обоих концов каждого veth и устанавливает четыре permanent neighbor entries. Router использует to_browser/to_server и адрес endpoint .10. Endpoint использует bench0 и адрес router .2 в своей подсети. Временный router helper получает NET_ADMIN только для установки записи в namespace endpoint. Четыре JSON-снимка таблиц сохраняются в seal вместе с остальными первичными файлами.

Пакет меняет только будущий сбор. Исторические raw и их hashes сохранены. Сверка losses/drops не ослаблена, частоты и критерии не менялись. Дефекты временной сетки и статистическая зависимость требуют отдельного решения.

Пять коротких offline тестов прошли. Два новых исполняют настоящий shell-фрагмент с подставным Docker, сверяют все четыре адреса, MAC, интерфейса и namespace, проверяют остановку при ошибке установки. Три существующих теста защищают строгий подсчёт потерь, разделение collection ID и saturation window. Реальной проверки kernel neighbor entries и сети не выполнялось. Независимая приёмка запрошена у координатора.
