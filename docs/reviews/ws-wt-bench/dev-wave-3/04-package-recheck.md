# Дополнение к приёмке D3

Рецензент `/root/dev_wave_3_reviewer_routed`. Запрошены `gpt-6-astra` и effort `high`, подтверждённые инструментом значения — unknown. Коммит `4711a9e3b1329f5ac02cf13f9204c031a89d9d59` содержит вызовы docker/check-sample.sh и пропускает сам файл. Проверяемая копия файла использовалась при независимом ревью и присутствовала в замороженном рабочем дереве.

SHA-256 docker/check-sample.sh — `1b2a635f0a6195e89de20db9ccd6f328b6238016e541a2f6d987f7a2df0339ed`. Проверены sh -n, точки вызова перед браузером, при стабилизации и при финальном отсчёте. Отдельная проба в удаляемом Linux-контейнере без сети приняла свежую строку и равенство финальной границе, отвергла устаревшую и пустую запись. Проба использует штатный порядок полей docker/sample.sh. Помещение end_usec первым полем вручную собранного JSON меняет поведение текстового разбора; сборщик всегда выводит это поле внутри строки после sample_index.

**Включение проверенного файла в отдельный исправляющий коммит принято.** Вердикт [03-recheck](03-recheck.md) относится к полному дереву D3 с этой версией файла. Экспериментальные проверки остаются not_run/deferred_by_user.
