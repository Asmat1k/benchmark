# Предварительный анализ версии 1

Основные сравнения — WS и WT-S внутри каждого из четырёх профилей. WT-D описывается отдельно. Предварительно 20 блоков на профиль и 4 сессии с пятью такими блоками в каждой. PCG64/SeedSequence с master 20261108 заранее определяет порядок блоков и режимов, раздельные ветви для серий, расписания, потерь вперёд/назад, bootstrap и power. Прогоны последовательны. Пары связываются по series/session/profile/block/attempt. Seed не удостоверяет независимость.

Для каждого блока D = Q_WT-S − Q_WS, θ оценивает медиану D. Двусторонняя H0 требует одновременно P(D>0)≤1/2 и P(D<0)≤1/2. При полном n, включая связи, N+ и N− — числа строго положительных и отрицательных D. Для B~Bin(n, .5) p=min(1, 2 min(P(B≥N+),P(B≥N−))). Holm4 сортирует четыре p, умножает по порядку на 4,3,2,1, берёт накопленный максимум и ограничивает 1, восстанавливает исходный порядок. Отклонение при p_adj<.05. Любой null Q в основной паре оставляет профиль unavailable, в Holm4 вносится placeholder 1. Такой результат не интерпретируют как проверенную H0.

Для каждой медианы показать 95% и 98.75% интервал. При α берут максимальное k с 2P(B≤k−1)≤α. Интервал [D_(k),D_(n−k+1)] с D_(0)=−∞, D_(n+1)=+∞. Для n=20 ранги [6,15]/[5,16], при n=5 95% интервал бесконечен. Оценка φ — среднее парных S_WT-S−S_WS в п.п. Для каждого профиля 10000 раз выбрать с возвращением n целых блоков, сохраняя обе стороны пары. Из средних разностей взять linear percentile .00625/.99375. Сохранить seed и indices. Для WT-D показать описательные 95% ДИ среднего S и медианы прогонных Q, явно указать null. Вырожденный bootstrap крайних долей не исключает редких отказов.

По одновременному ДИ θ верхняя граница <−5 мс поддерживает WT-S, нижняя >5 мс поддерживает WS. Интервал внутри [−5,+5] поддерживает практически малую разницу, прочие пересечения дают неопределённость. Для полезного выигрыша каждый основной прогон должен иметь U≤1%, без разрывов обоих режимов. Для WT-S нужна нижняя граница ДИ φ≥−1 п.п., для WS верхняя≤+1. Статистический, практический вывод, полнота и валидность отражаются отдельно по профилям.

Эталоны sign для 20 нулей, 10 единиц+10 нулей, 10 отрицательных+10 положительных дают p=1. Для 20 единиц p=2/2²⁰, для [1..5] p=.0625. Holm для [.01,.04,.03,.002] даёт [.03,.06,.06,.008]. Константа ΔS=−.5 даёт обе границы −.5. До расчётов проверяют checksums, схемы, completion, ledger, парность и счётчики. При повторе counts, ID, ранги, решения и знаки бесконечностей совпадают точно, конечные числа с абсолютным допуском 1e−10, bootstrap по сохранённым indices.
