# Анализ результатов

`./scripts/analyze-comparisons.sh [SERIES]` дополняет сохранённый all-outcomes отчёт семью сравнительными графиками в новом каталоге `SERIES/analysis-reports/comparisons-…/`. Без аргумента путь серии берётся из `build/latest-experiment`; тот же интерфейс доступен через `make compare SERIES=…`. Исходная серия и `derived` не перезаписываются. Контрольные суммы отчёта и файлов валидных прогонов проверяются до построения. Этот путь нужен для сохранённых серий после изменения кода: повторный допуск не выполняется, исходные статусы сохраняются.

Графики разделены по сетевым профилям: ECDF RTT ответов в пределах горизонта, точки и boxplot Q/S/U по прогонам, описательные парные разницы WT-S−WS по Q/S/U, ECDF лага всех отправленных слотов валидных прогонов и исходы назначений. WS обозначен синим, WT-S оранжевым, WT-D зелёным. Непринятые наблюдения имеют отдельные обозначения и не входят в boxplot и парные разницы. Линия 100 мс на RTT — ориентир, фактический дедлайн включает лаг отправки. ECDF взвешена по ответам/слотам; выводы по случайно доступным полным парам не делаются. Автономные тесты: `make comparison-test`.

`make analyze SERIES=path/to/series` запускается после измерений. Для exploratory-browser-study-v2 отчёт включает каждое назначение: complete, rejected, failed, interrupted, running и not_run. Для старой неполной серии используется `ARGS=--all-outcomes`. Исходные данные не изменяются; результат создаётся в SERIES/derived/.

Выходы: report.md, analysis.json, runs.csv, rtt.csv, графики PNG/SVG/PDF и SHA256SUMS. Все записанные правильные ответы остаются в rtt.csv с ID, лагом и признаками своевременности/горизонта. Для отклонённых и неполных данных показываются доступные наблюдения и причины ограничений; полные Q/S/U выдаются только для валидного raw.

При полной сравнительной серии доступны pairs.csv, profiles.csv, descriptive.csv и bootstrap-*.npz. Основное сравнение — WT-S−WS отдельно в четырёх профилях: полный знаковый тест с ties, Holm4, интервалы медианы 95%/98.75% и 10000 bootstrap-выборок целых парных блоков для среднего ΔS. WT-D описывается отдельно. Seeds и индексы bootstrap сохраняются. Практические границы — 5 мс для Q и 1 п.п. для S; полнота и disconnect оцениваются отдельно.

Неполнота или null не заменяются выводом по удобным парам. Новый режим остаётся исследовательским: исторические статусы calibration/generator failed и A/A partial сохраняются в политике, полная приёмка и мощность 80% не заявляются. Старый строгий анализ остаётся отдельным путём.

При ошибке анализа предыдущий derived не считается новым отчётом. Автоматическое построение после серии пишет причину отказа в analysis.stderr.log и analysis-exit.json.
